数当てゲーム

この講義では、数当てゲームを作りました。数当てゲームではテキストボックスを配置し、その左側にテキストボックスに対する説明と右側に回答を提出するためのボタンを設置しました。数当てをやる際に回数の値を1ずつ増やしていくという処理を実装しました。

数当てゲームのページ:kazuate.html

各授業会の学習事項

第1回 WWW と HTML

第1回の授業ではHTMLの基礎とされるホームページ作成の基本から学び始め、HTMLの主な要素である多数のタグの活用方法について学ぶとともにWWW（World Wide Web）とWebページの関係性と技術要素について学びました。

演習の成果:演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

第2回の授業ではCSSの機能を使ってWebページの装飾を行いました。スタイルシートを参照し、セレクタ、プロパティ名、プロパティ値を指定することで文字の色を変えるなどより良いレイアウトを追求しました。

演習の成果:演習2-3: ウェブブラウザの紹介

第3回 JavaScript の基本

第3回の授業ではJavaScriptを使い、ファイルを参照する方法を学びました。ファイル内から必要な情報を配列から抜き出しました。

演習の成果:演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

演習の成果:演習4-10: 足し算ページ

第5回 イベント処理

第1回の講義では、HTMLがかず多くの種類の要素からbなっているということ、そしてその要素に属性を追加していること、HTMLの[お約束]について学びました。演習1-4では見出しにリスト要素、ハイパーリンクを設置し、画像を貼りました。 第2回ではCSSによる見た目の装飾について学び、HTMLのhead要素にCSSのデータを引用できるようにするlink要素の記述方法、箇条書きの点をなくしたり文字やリンクの色を変更する方法について学びました。演習2-3では外部スタイルシートを設定し、文字サイズと背景色、レイアウトの変更、文字に影を追加する、グラデーションを使うなどを実行しました。 第3回ではJavaScriptで可能になることを学び、HTMLのscript要素の中にJavaScriptプログラムを入力し、文字を出力する方法、HTMLファイルとは別に外部のJavaScriptファイルを作成する方法を学びました。また、JavaScriptとJavaプログラムの違いや、JavaScriptの構文、デバッグについて学びました。 第4回ではイベント処理について学び、フォーム要素(HTML)、イベント要素(JavaScript)、DOMの3つを組み合わせました。input要素は種類がたくさんあり、そのページを開くブラウザによってユーザーインターフェイスに多少の差異がありました。検索要素にボタンの配置、イベントハンドラの確認などとにかくやることが多いという印象でした。演習4-10ではウェブ開発ツールのコンソールを開いて1つずつ文を確認しながらイベントの作成を実行しました。 第5回でもDOMについて学び、要素の新規作成、要素の編集、要素の削除のやり方を教えてもらいました。演習5-7ではfor-of文を使い学科一覧を新規作成し、ボタンを押したら一気に変更されるというイベントの作成をしました。

演習の成果:演習5-7: DOMプログラミング(2)
